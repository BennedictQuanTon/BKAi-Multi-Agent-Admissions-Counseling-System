Adaptive routing
Unambiguous, in-scope, single-turn questions skip the LLM supervisor → 1 LLM call per answer (avg 0.98 measured). Multi-turn / counselling / uncertain scope → 2 calls.
Where the time goes (fast path)
guard 0.3 ms · cache 25–60 ms · SQL tools 1–3 ms · hybrid search + rerank ~300 ms · Gemini TTFT ~0.8 s · stream ~1 s · verifier <5 ms.
Isolation
