Why “multi-agent” is now true
Each specialist owns its tools and its own decision logic (data: resolve → SQL → missing-year fallback · policy: search → judge → corrective hop · counsel: compute → compare). The supervisor fans out through parallel conditional edges; evidence merges through a list reducer.
Cost & latency
0–2 LLM calls per answer (v4: 2–4). Tools run in worker threads, never on the event loop. Quota-aware Gemini pool fails over to 3.1 Flash-Lite on 429/503.
